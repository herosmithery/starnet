## Running it in the background on free models
- Free OpenRouter models allow **50 requests/day** — one deep research task used ~60 steps. A **one-time $10 credit top-up raises the free-model cap to 1,000/day** (OpenRouter's documented limit); that is the cheapest way to run several agents daily.
- Schedule work with StarNet cron (CREW → agent → schedules), not Night Shift, until each routine has run clean for a week.
- Every post, DM, email, listing and payment stays behind your approval (Telegram).
